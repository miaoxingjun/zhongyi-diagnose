中医辨证诊断总技能
综合《内经·素问》《内经·灵枢》《小言黄帝内经》《伤寒论》《金匮要略》《神农本草经》《本草纲目》《中药基本理论知识》《针灸甲乙经》《经络图解》《腧穴》《穴情赋》《穴位图解》《中医伤科按摩学》《中医眼科备读》《中医养生学》《自我调养巧治病》《千金翼方》《千金要方》《邹孟城三十年临证经验集》等20部典籍，按症状追问→辨证分型→给方案的路径进行诊断。

一、通用诊断流程（所有症状适用）
确认主症：主要不适是什么？部位在哪？
追问症状特征（按分型需要问）：
寒热：怕冷还是怕热？有无发热？
汗出：有汗还是无汗？
疼痛性质：胀痛、刺痛、隐痛、冷痛、灼痛？
分泌物/排泄物：清还是浊？稀还是稠？颜色？
口渴：想喝热水还是冷水？
饮食睡眠：胃口如何？睡眠如何？
舌脉（如能描述）：舌质、苔色？
辨证分型：根据症状组合判断证型。
给出方案：起居调养 + 饮食调养（食疗）+ 药物/方剂 + 针灸推拿。
二、辨证分型体系（按理论框架选择）
A. 阴阳脏腑辨证（《内经·素问》）
辨阴阳：症状偏阴（寒、静、虚）还是偏阳（热、动、实）？
辨脏腑：心主血脉神志、肝主疏泄藏血、脾主运化统血、肺主气司呼吸、肾主水纳气
辨病因：六淫（风寒暑湿燥火）、七情、饮食劳倦、外伤
辨气血津液：气虚/气滞、血虚/血瘀、津液亏虚/痰湿
治则：治未病、标本缓急、正治反治
B. 六经辨证（《伤寒论》——外感病）
太阳病：表证，发热恶寒、头项强痛、脉浮 → 麻黄汤/桂枝汤
阳明病：里热实证，大热大汗大渴、脉洪大；或腑实（便秘腹痛）→ 白虎汤/承气汤
少阳病：半表半里，寒往来之、胸胁苦满、口苦咽干 → 小柴胡汤
太阴病：里虚寒，腹满而吐、食不下、自利
少阴病：心肾虚寒或虚热，脉微细、但欲寐
厥阴病：寒热错杂，上热下寒、厥利
追问关键：寒热有无、汗有无、口渴与否、二便、胸腹症状
C. 杂病辨证（《金匮要略》）
辨病与辨证结合：先辨病（百合病、脏躁、胸痹），再辨证型
病机：血瘀水饮（痰饮、水气病）、情志病（脏躁、百合病、梅核气）、胸痹心悸奔豚
经方思路：苓桂术甘汤治水饮、甘麦大枣汤治脏躁、瓜蒌薤白汤治胸痹
D. 体质辨识（《中医养生学》——九种体质）
平和质：精力充沛、面色润泽
气虚质：气短懒言、易出汗、易疲劳
阳虚质：畏冷、手足不温、喜热饮
阴虚质：口燥咽干、手足心热、便干
痰湿质：形体肥胖、胸闷痰多、口黏
湿热质：面垢油光、易生痤疮、便黏
血瘀质：肤色暗沉、唇色紫暗、易出血点
气郁质：情绪低落、忧思多、胸胁胀满
特禀质：易过敏、荨麻疹、过敏性鼻炎
结合四时：春生、夏长、秋收、冬藏
E. 生活方式养生（《小言黄帝内经与生命科学》）
了解作息、饮食、运动、情志、工作压力
对照养生原则：顺应四时、饮食有节、起居有常、不妄作劳、形与神俱
找出违背养生之道的环节，结合现代营养学、作息管理、情绪调节给方案
三、分科诊断
A. 骨伤按摩（《中医伤科按摩学》）
明确伤处：疼痛部位？筋骨、关节、还是肌肉？
追问病因：有无外伤史（闪挫、扭挫、跌打）？急性还是慢性劳损？
辨析症状：刺痛（血瘀）vs 酸痛（筋急）；有无瘀青血肿；活动度是否受限；有无畸形/异常活动/骨擦音（警惕骨折脱位）
辨证分经：按十二经脉、筋骨定位判断所属经络脏腑
给手法：理筋、整复、点穴及功能锻炼
常见伤症：颈椎病、腰椎间盘突出、急性腰扭伤、腰椎骨质增生；腱鞘炎、肱骨外上髁炎、肩周炎、坐骨神经痛、腕管综合征、足跟痛；肩/肘/指关节脱位；骨折/神经损伤后遗症 有骨折、脱位、肿瘤、感染、脊髓损伤征象者先排除禁忌，建议影像学检查，不盲目推拿

B. 眼科（《中医眼科备读》）
视力变化：视物模糊/变形/变色/缺损？突发还是渐进？
眼局部：疼痛性质、涩感、分泌物、眼睑（红肿下垂麦粒肿）、白睛（红赤血丝黄染）、黑睛（白膜翳障）、瞳仁（匀称与否、对光反射）
五轮分部：胞轮→肉轮→血轮→气轮→水轮，判断脏腑
结合全身症状辅助辨证
给证型治法：风热上扰、肝火上炎、阴虚火旺、脾胃湿热
常见眼病：麦粒肿、上睑下垂、睑缘炎；结膜炎、角膜炎、白内障、青光眼；视神经萎缩、视网膜病变 突发性视力下降、眼痛伴头痛恶心、视野缺损等需紧急眼科检查

四、经络取穴（按症状部位选穴）
A. 经络辨证（《经络图解》）
定位循经：症状沿哪条经络分布？（十二正经、奇经八脉）
辨析性质：冷（寒凝）vs 热（郁热）vs 麻（血虚血瘀）vs 木（气血不通）
判断所属脏腑：经络属络脏腑（如肺经病见胸痛咳）
给建议：循经取穴、按摩艾灸、经络拍打
十二经络症状归属速查：

肺经：胸满、咳、咽喉痛、上肢前内侧痛
胃经：头面、前胸腹、上肢及下肢前外侧、胃腑病
脾经：脾胃病、舌本痛、下肢内后侧痛
心经：心病、胸胁痛、上肢内后缘痛、舌痛
小肠经：头侧、耳、肩背、上肢内后缘、咽喉
膀胱经：头项、背腰、下肢后侧、脏腑背俞穴病
B. 常用穴速查（《穴位图解》）
头面：合谷、印堂、太阳、风池
胸肺：膻中、中府、尺泽、太渊
脾胃：中脘、天枢、足三里、内关
肾/泌尿：太溪、关元、肾俞、三阴交
安神：神门、百会、四神聪、三阴交
效穴速查：头痛→合谷、风池、印堂；胃痛→中脘、足三里、内关；失眠→神门、百会、三阴交；感冒→合谷、大椎、风门；颈肩→肩井、颈百劳、外关 取穴法：骨度分寸、同身寸或简便取穴法；按揉力度以酸胀为度

C. 腧穴精取（《腧穴》——特定穴）
明确症状与病位：属何经何脏
本经穴 + 表里经穴（归经配穴原则）
善用特定穴：五输穴（井荥输经合）、原穴、络穴、俞穴、募穴、八会穴、八脉交会穴
骨度分寸法精确取穴，结合解剖标志
针刺深度方向、灸法、推拿手法
穴性要点：眼周胸背项部穴位深浅有度；原穴治本经脏腑病、络穴治表里两经病

D. 穴情赋要诀（《穴情赋》）
诵读赋文要诀，对照穴位赋文主治归纳
症状归经归类，对应赋文主治范畴
给主治穴位及操作建议
E. 针灸取穴（《针灸甲乙经》）
辨病位与所属经络：按书中经络分类归纳症状
查找主治条文：对应穴位主治记载
给取穴与针刺灸法方案
针刺操作需专业资质；保健以按摩艾灸为宜

五、中药用药（按症状性质选药）
A. 药性用药（《中药基本理论知识》）
辨证定性：寒/热/虚/实？属何经何脏？
匹配药性：
四气：寒热温凉（寒者热之、热者寒之）
五味：辛散、甘缓、酸收、苦降、咸软、淡渗
归经：药入何经，对症归经选药
升降浮沉：顺应病势（表证用升浮、逆行者用沉降）
功效分类用药：解表药、清热药、补虚药、活血化瘀药
提示剂量与配伍禁忌（十八反、十九畏）
常用中药分类：

解表：麻黄、桂枝、薄荷、菊花
清热：石膏、黄连、金银花、板蓝根
补虚：人参、黄芪、当归、熟地
理气：陈皮、柴胡、香附
活血：川芎、丹参、桃仁、红花
B. 上品选药（《神农本草经》）
辨证定性：寒虚归属何经
按分级选药：上品（养命、可久服）、中品（养性、治病）、下品（治病、多毒）
给性味功效与用法
下品多有毒性，须专业指导，不可自用

C. 药食同源（《本草纲目》）
辨症状性质：寒虚，归属何经
检索药物：按草部、谷部、菜部、果部、虫兽部、等分类查找对症药物
给性味归经与功效：如生姜辛温解表、大枣甘温补脾
给食疗/药膳思路（药食同源者优先）
六、方剂与经验方
A. 翼方要方（《千金翼方》《千金要方》）
辨证分型：寒热虚实归属脏腑
匹配方剂：参考书中方剂（如百合知母汤、温胆汤等）
给食疗与养生调护
B. 临证经验（《邹孟城三十年临证经验集》）
辨主症与兼症：明确主诉及伴随症状
辨病因病机：外感内伤、气血津液、脏腑失调
匹配经验治法与方药：参考同类病证的辨证思路与用药特点
七、通用注意事项
急重症（胸痛、大出血、意识障碍、突发性视力下降、眼痛伴头痛恶心等）立即就医，不替代诊疗。
经方/经验方/中药用药须中医师辨证指导，勿自行抓药。
针刺操作需专业资质；非专业人士仅可按摩、艾灸保健。
孕妇禁按合谷、三阴交、肩井等；腹部穴位不宜重按；皮肤破损处不宜推拿。
有骨折、脱位、肿瘤、感染、脊髓损伤征象者，先排除禁忌，建议影像学检查。
食疗方剂量仅供参考，养生调理重在长期干预。
